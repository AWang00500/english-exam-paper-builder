# 英文考卷製作工具（English Exam Paper Builder）

專為教師設計的紙本英文翻譯考卷製作網頁工具，支援即時所見即所得編輯、五題一欄直向自動排版、獨立配分計算、區塊拖曳排序，並可匯出真正可編輯的 Word（`.docx`）、可列印向量 PDF，以及可本機離線獨立開啟的單一 HTML 檔案。

---

## 主要功能

### 1. 考卷標題與基本資料區
- 預設包含考卷總標題（`英文單字測驗`）與學生基本資料（`班級`、`姓名`、`座號`、`日期`）。
- **所有文字皆可直接點擊修改**，不鎖定任何預設內容，並可新增或刪除基本資料欄位。
- 支援**拖曳調整位置**：可拖動「考卷標題」與「基本資料區」互換上下排列順序，亦可左右拖曳調整各基本資料欄位順序及文字對齊方式（靠左／置中／靠右）。

### 2. 中翻英與英翻中題目區
- 預設區塊標題為「中翻英」與「英翻中」，皆可直接點擊修改。
- 點擊 **「＋新增一題」**（或在題目輸入框按下 `Enter`）即可直接於考卷預覽位置新增並對焦輸入。
- 每道題目旁附有垃圾桶圖示，點擊即可刪除並自動重新編號；題目後方統一產生相同長度的空白作答底線（足以手寫 10 個以上英文字母）。
- **五題一欄直向排版**：
  - 每一欄由上而下直向排列 5 題（第 1～5 題為第一欄）。
  - 超過 5 題時自動往右增加下一欄（第 6～10 題為第二欄），不足 5 題時不強制補滿空白題列。
  - 工具列提供「每列 2 欄／每列 3 欄」切換，兼顧 A4 直式列印閱讀性。

### 3. 獨立配分系統（自動平均／手動配分）
- **中翻英與英翻中各自獨立計算**，預設每大題總分為 `100` 分。
- 預設為**自動平均配分**：新增或刪除題目時，系統自動將總分平均分配給該區塊所有題目（亦可直接調整該區塊預設總分）。
- **手動配分保護機制**：只要手動修改任一題的配分，該區塊立即解除自動平均模式；解除後將保留手動配分，後續新增或刪除題目皆不會擅自更動其他題目的分數。若需恢復自動平均，可點擊「恢復自動平均」按鈕。

### 4. 區塊拖曳調整順序
- 支援以拖曳手把（或「對調」按鈕）拖動整個「中翻英」或「英翻中」區塊交換上下位置，題號（`一、`、`二、`）與匯出結果會同步更新。
- 僅允許拖動整個題目區塊，不提供單獨拖動個別題目，以維持五題一欄的整齊結構。

### 5. 其他題目留白區塊
- 考卷最下方提供 **「＋加入留白區塊」** 按鈕，供教師預留手寫題目或補充空間。
- 留白區塊固定位於所有正式題目區塊下方，不含標題、題號、配分或作答格，僅提供乾淨空白區域，並可重複加入與各自獨立刪除。

### 6. A4 考卷預覽、列印與多格式匯出
- **真實 A4 直式分頁預覽**：依據實際內容高度自動分頁，不會將題目文字、答案底線或大題標題截斷於頁緣；瀏覽器列印（`@media print`）時會自動隱藏所有編輯工具列與按鈕。
- **匯出 Word（`.docx`）**：透過 `docx` 套件產生真正可於 Microsoft Word 開啟與繼續編輯的 A4 直式文件，完整保留欄位排版、配分與留白區塊。
- **匯出 PDF（`.pdf`）**：透過 `jsPDF` 搭配 `Noto Sans TC` 繁體中文字型繪製向量可列印 A4 PDF（非網頁截圖）。
- **下載單檔 HTML**：工具列提供 **「下載單檔」** 按鈕，可直接下載整合完整程式與樣式的單一 HTML 檔案（`英文考卷製作工具_單檔版.html`），無需架設伺服器即可雙擊開啟運行。

## 技術架構

- **前端框架**：React 19 + TypeScript + Vite 8
- **樣式設計**：Tailwind CSS v4
- **拖曳排序**：`@dnd-kit/core`、`@dnd-kit/sortable`、`@dnd-kit/utilities`
- **文件匯出**：`docx`（Word `.docx` 產生）、`jspdf`（向量 PDF 產生）
- **單檔打包**：`vite-plugin-singlefile`
- **圖示庫**：`lucide-react`

---

## 安裝與執行

### 安裝相依套件
```bash
npm install
```

### 啟動開發伺服器（預設連接埠 3000）
```bash
npm run dev
```

### 型別檢查
```bash
npm run lint
```

### 建置正式版與獨立單檔 HTML
```bash
npm run build
```
建置完成後：
- `dist/index.html` 即為完整自包含的單一可獨立運行網頁檔案。
- 同時會同步輸出至 `public/standalone.txt`，供網頁介面中的 **「下載單檔」** 按鈕直接提供下載。

## 專案目錄結構

```text
├── index.html                  # 網頁進入點與字型載入設定
├── vite.config.ts              # Vite 與 vite-plugin-singlefile 建置設定
├── src/
│   ├── App.tsx                 # 主應用程式狀態管理與匯出／暫存控制
│   ├── index.css               # Tailwind CSS 與 A4 @media print 列印樣式
│   ├── types/
│   │   └── exam.ts             # 考卷資料結構與型別定義
│   ├── utils/
│   │   ├── defaultExam.ts      # 預設考卷範例資料
│   │   ├── scoring.ts          # 獨立自動／手動配分邏輯
│   │   ├── pagination.ts       # 五題一欄分欄與 A4 自動分頁演算法
│   │   ├── exportDocx.ts       # Word (.docx) 文件匯出器
│   │   └── exportPdf.ts        # 向量 A4 PDF 文件匯出器
│   └── components/
│       ├── TopToolbar.tsx      # 頂部操作列（欄數切換、列印、單檔下載、匯出）
│       ├── ExamPaperWorkspace.tsx # A4 分頁工作區與區塊拖曳排序容器
│       ├── ExamHeaderBlock.tsx # 考卷標題與基本資料編輯／拖曳區塊
│       ├── SectionHeaderBar.tsx# 大題標題、配分狀態控制與拖曳手把
│       ├── QuestionBandView.tsx# 五題一欄直向題目列與作答空格元件
│       └── BlankBlockView.tsx  # 考卷底部留白區塊元件
└── public/
    └── standalone.txt          # 供網頁「下載單檔」按鈕使用的最新建置單檔
```
